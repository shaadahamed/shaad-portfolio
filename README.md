# Shaad Ahamed — Professional Portfolio Website

A responsive, single-page portfolio website for GitHub Pages.

## Files
- `index.html` — portfolio content and page structure
- `styles.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** named `shaad-portfolio` (or another name you prefer).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will publish the website. The address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/shaad-portfolio/`

## Before publishing
- Check every role description and qualification for accuracy.
- If your current official title is different from “Team Leader – Administration”, update it in `index.html`.
- Add your own LinkedIn profile link if you want one displayed.
- To add a CV download button, place your final CV PDF in this folder (for example `Shaad-Ahamed-CV.pdf`) and add a link in the hero section:
  `<a class="button secondary" href="Shaad-Ahamed-CV.pdf" download>Download CV ↓</a>`
- Consider adding a professional headshot by replacing the `SA` initials avatar with an image you are comfortable sharing.

## Editing
You can edit `index.html` in GitHub directly, or download the repository and edit it with VS Code. No build tools are required.
